# cs2114-project1-group73
Restaurant Suite for waitlists and table management.
1. Create a new javaproject in eclipse with javaSE-17 or newer. \n
2. Download the src/mainClass Folder \n
3. replace the blank src file with the src/mainClass folder or add the files into the default src folder under the mainClass package \n
4. Navigate to the javaproject properties -> java build path, add the student.jar file as an external JAR file. (this is located in the mainClass folder) \n
5. ensure the compiler is version 17 or newer. \n
6. run the main.java file and interact directly with the console
